# 仅时长活动的报告显示

手机继续记录地点到达/离开；Notion继续记录地点、活动名与持续时长，不要求每个活动的启停时间。新后端可将完整自然日的仅时长活动按地点归属，并合并同地点一天多次到访。原文缺地点、同名地点未能唯一确定、多个地点仅有一个合计时长时，报告显示待确认，不伪造活动钟点。

网页将有效时间描述为“已归属有效”。单个活动没有matched_start/end时仍显示原始分钟数；手机地点时间轴保持实际记录。多地点组合的总时长在待确认区域只显示一次，不在每家重复或按比例分配。历史报告读取不会调用模型或重新分析。

独立区间查询中，仅时长活动适用于完整自然日；只选几个小时无法确定其中包含哪些仅时长活动。利用率为“无法准确确定”时，不应把当前已归属值看作当天完整有效活动总量。

本次前端改动不改变PIN、存储键、计时记录或同步协议。后端匹配规则见Time-Management-Agent的docs/place-duration-matching.md。先进行离线验收，不直接部署或改动手机数据。
